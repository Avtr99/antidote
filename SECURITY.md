# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Report vulnerabilities through GitHub's private vulnerability reporting on the
[Security tab](https://github.com/Avtr99/antidote/security/advisories/new), or
open a [GitHub Security Advisory](https://github.com/Avtr99/antidote/security).

Do not open public issues for security reports. You will get a response as soon
as possible, and fixes ship in a patch release once confirmed.
